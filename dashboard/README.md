# Dashboard app

This is the Angular app for The Three Stooges. The project description, how to run it locally, how to test it and how to deploy it are in the [root README](../README.md).

Quick start:

```
npm install
npm start      # sample data at http://localhost:4200, no sign-in
npm test
```

Working rules for this codebase are in [CLAUDE.md](CLAUDE.md).
